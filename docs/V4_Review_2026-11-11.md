Production Dual-T4 rendering is now explicitly **blocked** until a real canonical panel compositor is integrated; a mock-only path remains for isolated tests. **Not yet a functional video renderer.**

4. **Kaggle preview bypass & swallowed strict form error** — prohibited `--skip-preview` as an approval bypass and made missing/invalid 10-answer setup a validation error, not merely a log warning. Legacy default synthesis is no longer accepted as user approval.
5. **Archive receipt falsely verified immediately after upload** — archive push now marks `uploaded`; a separate `archive_verify` must SHA-256 check every remote file, not only metadata. Restoration must SHA-256 check every file. Verification/download failures are fatal.
6. **Unsafe cleanup bypass** — non-dry-run `--bypass-receipts` rejected; requires pinned manifest, verified archive and verified restore. YouTube receipt must be `verified` and `processed`, not merely `uploaded`.
7. **YouTube false success conditions** — video verification requires original upload receipt, matching account/project/video, processed status, chosen privacy and explicitly requested attachments; metadata update repaired.
8. **HF privacy and secret leakage** — require a confirmed private dataset repo; reject symlinks (including to secrets inside project root). Declare `huggingface_hub` package dependency.
9. **Unverifiable reports** — reports claiming empirical T4/remote HF success were replaced with explicit NOT VERIFIED audit records; no live GPU/HF jobs were performed as part of this review.
